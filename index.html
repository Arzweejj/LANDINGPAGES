Tentang Saya

Saya adalah siswa kelas 11 SMK jurusan Rekayasa Perangkat Lunak (RPL) yang memiliki ketertarikan pada dunia teknologi dan pemrograman. Saya senang mempelajari HTML, CSS, Java, Python, serta membuat berbagai proyek website dan aplikasi. Selain belajar pemrograman, saya juga suka bermain game, membaca manga, menonton anime, dan mengeksplorasi hal-hal baru. Saya terus berusaha mengembangkan kemampuan saya dalam bidang teknologi dan menjadi lebih baik melalui setiap proyek yang saya kerjakan.

Proyek saya

Perpustakaan Mediterenia merupakan proyek sistem perpustakaan yang saya buat menggunakan Python. Sistem ini memiliki fitur katalog buku, login admin dan tamu, peminjaman dan pengembalian buku, serta pencatatan denda apabila buku terlambat dikembalikan.

Website Portofolio Pribadi merupakan proyek website yang saya buat menggunakan HTML dan CSS. Website ini digunakan untuk menampilkan informasi tentang diri saya, kemampuan, serta beberapa tautan media sosial. Saya juga menerapkan berbagai desain seperti gradient, hover effect, dan layout yang responsif agar website terlihat lebih menarik.
